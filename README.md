# FactoryMargin AI — Research References

This folder contains repository-ready research documentation for FactoryMargin AI.

## Files

- `docs/REFERENCES.md` — annotated reference list, relevance to product modules, and a suggested validation plan.
- `references.bib` — BibTeX entries for use in reports, papers, and technical documentation.

## Add to an existing repository

Copy `docs/REFERENCES.md` into your repository's `docs/` folder and copy `references.bib` into the repository root (or your preferred bibliography folder).

Add this to the main `README.md`:

```markdown
## Research and references

See [docs/REFERENCES.md](docs/REFERENCES.md) for the research basis behind supplier evaluation, manufacturing cost estimation, procurement workflows, and responsible AI. BibTeX entries are available in [references.bib](references.bib).
```

## Citation note

Cite the original publications when reusing ideas or claims. Do not copy abstracts or figures into the project without checking publisher licensing. The references support design rationale; prototype performance claims must come from your own documented testing.
